# Módulo `auth`

**Responsabilidad:** registro, login, refresh y logout. Emisión y verificación de JWT de acceso, gestión de refresh tokens (rotación y revocación), hash de contraseñas con argon2id, verificación de mayoría de edad.

**Implementación planificada:** Sprint 1 (`docs/07-plan-trabajo.md`).
