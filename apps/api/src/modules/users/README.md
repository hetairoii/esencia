# Módulo `users`

**Responsabilidad:** gestión de la cuenta y del perfil propio (crear y editar el perfil sin fotos, preferencias de descubrimiento) y eliminación de cuenta. Recalcula `isDiscoverable` en cada cambio relevante.

**Implementación:** Sprint 1 (perfil y preferencias) y Sprint 4 (eliminación de cuenta); ver [`docs/07-plan-trabajo.md`](../../../../../docs/07-plan-trabajo.md).
