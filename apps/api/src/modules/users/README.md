# Módulo `users`

**Responsabilidad:** gestión de la cuenta y el perfil propio (crear/editar perfil sin fotos, preferencias de descubrimiento) y eliminación de cuenta. Recalcula `isDiscoverable` en cada cambio relevante.

**Implementación planificada:** Sprint 1 (perfil y preferencias), Sprint 4 (eliminación de cuenta) — ver `docs/07-plan-trabajo.md`.
