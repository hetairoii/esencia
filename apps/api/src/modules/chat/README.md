# Módulo `chat`

**Responsabilidad:** mensajería en tiempo real vía Socket.IO (namespace `/chat`) entre usuarios con match, historial persistido y paginado, marcado de leído/no leído. Usa el adaptador de Redis para sincronizar eventos entre réplicas del backend.

**Implementación planificada:** Sprint 3 (`docs/07-plan-trabajo.md`).
